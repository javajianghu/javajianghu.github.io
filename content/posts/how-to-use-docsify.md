## 官方网站
[https://docsify.js.org/#/zh-cn/](https://docsify.js.org/#/zh-cn/)

```
# 安装
npm install docsify-cli

# 初始化项目，并在./docs写文章，如果已经初始化过了，则跳过本步骤
docsify init ./docs

# 启动项目
docsify serve ./docs

# 对于本项目
docsify serve ./
```
